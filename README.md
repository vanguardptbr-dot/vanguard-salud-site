# Vanguard Salud

Site em espanhol do rosto hispano da Vanguard School of Professional Health (Lauderhill, Flórida).

- Feito a partir do site em português (vanguardptbr-dot/vanguard-saude-site, commit 855b260), com a mesma estrutura e o mesmo visual.
- Site estático: index.html com CSS e JavaScript dentro, mais a pasta assets. Não tem build.
- Logos em espanhol: assets/logo-horizontal-es.png (topo) e assets/logo-vertical-branco-es.png (rodapé), do branch logos-espanhol do repositório em português.
- Oferta de fim de ano marcada no código com comentários "promo". Some sozinha em 1/1/2027.
- WhatsApp: variável WHATSAPP no script, o mesmo número do rosto brasileiro.
- Deploy pela Hostinger a partir do branch main, só depois da confirmação do responsável.
